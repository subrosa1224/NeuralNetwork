## 各模块约定

| 边界 | 约定 |
|---|---|
| 原始数据 | `get_mnist_data(flatten=False)` 返回 `(N,28,28)`、范围 `[0,1]`，标签为整数 `(N,)` |
| 模型 | `forward(x) -> logits (N,10)`；`backward(dlogits) -> dx`；`parameters() -> [(参数数组, 梯度数组), ...]` |
| 交叉熵 | `forward(logits, labels)` 后 `backward()`；模型输出端不额外加 softmax |
| MSE | 训练框架将整数标签转换为 one-hot，再交给 `MSELoss` |
| 梯度缩放 | 损失使用默认 `mean`，层或优化器不再除一次 batch size |
| 优化器 | 构造时持有模型；`step()` 每次调用 `model.parameters()` 读取最新梯度并原位更新 |
| 训练 | `fit(model, train_loader, validation_loader, loss_fn, epochs, optimizer)` 返回逐轮记录列表 |
| 评估 | `evaluate(model, loader, loss_fn)` 返回 Loss、Accuracy、宏平均 Precision/Recall/F1 和样本数 |
| 模型文件 | `.npz` 参数名稳定，`__config__` 保存 JSON 配置；`load_checkpoint()` 返回模型和配置 |

当前层在每次 `backward()` 时覆盖梯度，因此基础 SGD 不需要额外清零。后续如果改成梯度累积，需要同步修改训练接口和测试。

## 运行与结果口径

完整运行使用 `configs/mlp.json` 和 `configs/cnn.json`。每次采用相同种子从 60,000 张训练图片中划出 5,000 张验证图片，最终评估官方 10,000 张测试图片。

小规模命令只用于联调，不能当作完整训练结果。`metrics.json` 记录实际训练、验证、测试样本数；实验对比时同时保存配置和 `history.csv`。默认保存最后一轮模型。

训练指标在当轮各批次更新前累计，验证指标在该轮更新结束后计算。曲线中的两者不代表同一时刻的模型表现。

本地实测使用 Python 3.9、NumPy 1.26.4；CI 使用 Python 3.11。当前 Mac 的 NumPy 2.0.2 曾对有限值卷积矩阵乘报告浮点警告，与独立计算结果一致；隔离环境使用 1.26.4 后相同计算无警告，因此依赖中固定了该版本。各成员使用 `requirements.txt` 建立环境。
